# MySQL Summary

## What you learned

Installing and using MySQL, databases and tables, data types, storage engines, string, number and date functions, pagination and search, variables, stored procedures, functions, triggers, events, views, indexes and EXPLAIN, relationships, transactions, JSON, users and permissions, backups, import and export, performance, security, and using MySQL from Python, PHP and Node.js.

## Next steps

1. Build the practice programs.
2. Connect MySQL to a real website using PHP or Node.js.
3. Learn about other databases such as PostgreSQL and MongoDB.
