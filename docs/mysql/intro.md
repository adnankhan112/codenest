# MySQL Introduction

MySQL is the most popular free and open source relational database. It is used by websites such as Facebook, YouTube and Wikipedia.

## Why MySQL?

- Free to use
- Fast and reliable
- Works on Windows, Mac and Linux
- Works well with PHP, Python, Java, Node.js and more
- Huge community

## MySQL and SQL

SQL is the **language**. MySQL is the **software** that stores your data and understands SQL.

## What you will learn

Installing MySQL, creating databases and tables, MySQL data types, functions, stored procedures, triggers, users, backups, performance and real practice projects.
