# MySQL Installation

## Windows

1. Go to dev.mysql.com/downloads and download **MySQL Installer**.
2. Choose **Developer Default** (it installs the server and MySQL Workbench).
3. Set a **root password** and remember it.
4. Finish the installation.

## Check that it works

Open a terminal and type:

```
mysql --version
```

## Easy way for beginners: XAMPP

XAMPP installs MySQL (MariaDB), PHP and a web server together. Start **MySQL** from the XAMPP control panel.

## Tools to use MySQL

- **MySQL command line**
- **MySQL Workbench** (a visual tool)
- **phpMyAdmin** (a web tool, comes with XAMPP)
