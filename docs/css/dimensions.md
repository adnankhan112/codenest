# CSS Height and Width

```css
div {
  width: 300px;
  height: 200px;
}
```

## Useful properties

| Property | Purpose |
| --- | --- |
| `width`, `height` | Set the size |
| `max-width` | The element never gets wider than this |
| `min-width` | The element never gets narrower than this |
| `max-height`, `min-height` | Same, for height |

## Responsive images

```css
img {
  max-width: 100%;
  height: auto;
}
```
