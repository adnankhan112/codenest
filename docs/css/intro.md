# CSS Introduction

CSS stands for **Cascading Style Sheets**. It controls how HTML elements look on screen: colors, fonts, spacing, layout and more.

## Why use CSS?

HTML gives a page its structure. CSS gives it style. Keeping them separate makes websites easier to build and maintain, and one stylesheet can style many pages.

## Example

```html
<!DOCTYPE html>
<html>
  <head>
    <style>
      body { background-color: lightblue; }
      h1 { color: white; text-align: center; }
      p { font-family: Arial; font-size: 18px; }
    </style>
  </head>
  <body>
    <h1>Hello CSS</h1>
    <p>This page is styled with CSS.</p>
  </body>
</html>
```
