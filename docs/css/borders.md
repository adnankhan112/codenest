# CSS Borders

```css
p {
  border: 2px solid black;
}
```

A border has a width, a style and a color.

## Border styles

`solid`, `dashed`, `dotted`, `double`, `groove`, `none`.

## Single sides

```css
div {
  border-bottom: 3px solid red;
  border-left: 5px dotted blue;
}
```

## Rounded corners

```css
.card {
  border: 1px solid gray;
  border-radius: 10px;
}

.circle {
  width: 100px;
  height: 100px;
  border-radius: 50%;
}
```
