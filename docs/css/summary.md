# CSS Summary and Practice

## What you learned

Selectors, colors, backgrounds, borders, spacing, the box model, text and fonts, display and position, flexbox, grid, transitions, animations, media queries and variables.

## Practice project

Style the personal page you built in the HTML tutorial:

1. Add an external `style.css`.
2. Give the page a color theme using CSS variables.
3. Build a navbar with flexbox.
4. Show your hobbies as cards in a grid.
5. Style the table with striped rows.
6. Make the layout work on phones using a media query.
