# CSS Best Practices

- Use an external stylesheet.
- Use meaningful class names, for example `.nav-link` instead of `.blue1`.
- Avoid inline styles and avoid `!important`.
- Reset spacing with `box-sizing: border-box`.
- Use variables for colors and spacing.
- Use `rem` and `%` for flexible sizes.
- Write mobile-first media queries.
- Keep good color contrast for readability.
- Group related rules and add comments.
