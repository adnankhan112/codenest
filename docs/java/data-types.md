# Java Data Types

Java has **primitive** types and **reference** types.

## Primitive types

| Type | Size | Example |
| --- | --- | --- |
| `byte` | 1 byte | `100` |
| `short` | 2 bytes | `30000` |
| `int` | 4 bytes | `1000000` |
| `long` | 8 bytes | `10000000000L` |
| `float` | 4 bytes | `3.14f` |
| `double` | 8 bytes | `3.14159` |
| `char` | 2 bytes | `'A'` |
| `boolean` | 1 bit | `true` |

## Reference types

`String`, arrays, classes and interfaces are reference types. They store the address of an object.

```java
String text = "Hello";
int[] numbers = {1, 2, 3};
```

Use `int` for whole numbers and `double` for decimals in most programs.
