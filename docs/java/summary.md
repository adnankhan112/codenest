# Java Summary and Practice

## What you learned

Syntax, variables, operators, strings, conditions, loops, arrays, methods, classes and objects, inheritance, polymorphism, abstraction, interfaces, collections, exceptions, files, lambda, streams, generics, threads, regex and JDBC.

## Practice projects

1. A calculator that reads numbers with `Scanner`.
2. A student management system using classes and `ArrayList`.
3. A bank account program with encapsulation and exceptions.
4. A to-do list saved in a text file.
5. A library system using inheritance and interfaces.
6. A word counter using `HashMap`.

## Next steps

Learn a framework such as **Spring Boot** to build web applications, or use Java to build Android apps.
