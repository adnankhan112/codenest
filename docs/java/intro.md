# Java Introduction

Java is one of the most popular programming languages in the world. It was created by James Gosling at Sun Microsystems and released in 1995.

## What is Java used for?

- Android apps
- Web servers and enterprise software
- Banking and financial systems
- Games (for example Minecraft)
- Big data tools

## Why learn Java?

- It is easy to read and well organized.
- It works on many systems. The idea is "write once, run anywhere".
- It has a huge community and many jobs.

## First program

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```
