# Java Comments

```java
// This is a single line comment

/*
   This is a
   multi-line comment
*/

/**
 * This is a documentation comment.
 * It is used to describe classes and methods.
 */
public class Main {
    public static void main(String[] args) {
        int x = 5; // comment after code
    }
}
```
