# HTML Comments

Comments are notes in your code that the browser does not display.

```html
<!-- This is a comment -->
<p>This paragraph is visible.</p>
<!-- <p>This paragraph is hidden.</p> -->
```

## Why use comments?

- To explain your code to yourself and others.
- To temporarily hide code while testing.

Comments start with `<!--` and end with `-->`.
