# HTML Paragraphs

The `p` element defines a paragraph.

```html
<p>This is a paragraph.</p>
<p>This is another paragraph.</p>
```

## Line breaks

Use `br` to break a line without starting a new paragraph.

```html
<p>Roses are red,<br>Violets are blue.</p>
```

## Preformatted text

The `pre` element keeps spaces and line breaks exactly as typed.

```html
<pre>
  Line one
      Line two
</pre>
```

## Remember

The browser ignores extra spaces and blank lines in your HTML. Many spaces or lines in the code still show as one space on the page.
