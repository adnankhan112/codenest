# HTML Best Practices

Follow these habits to write clean and correct HTML.

- Always start with `<!DOCTYPE html>` and set the `lang` attribute.
- Use lowercase element and attribute names.
- Close all elements that need an end tag.
- Always use quotes around attribute values.
- Add `alt` text to every image.
- Use semantic elements such as `header`, `main` and `footer`.
- Use headings in order, with one `h1` per page.
- Indent nested elements to make the code readable.
- Write meaningful `title` and description tags.
- Use short, descriptive file names without spaces, for example `about-us.html`.
- Check your code with a validator such as the W3C Markup Validation Service.
