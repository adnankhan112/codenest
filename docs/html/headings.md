# HTML Headings

HTML has six heading levels, from `h1` (most important) to `h6` (least important).

```html
<h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>
```

## Good practice

- Use only one `h1` per page, as the main title.
- Use headings in order, without skipping levels.
- Use headings for structure, not just to make text big or bold. Search engines and screen readers rely on them.

## Horizontal line

The `hr` element draws a line that separates content.

```html
<h2>Section One</h2>
<p>Some text.</p>
<hr>
<h2>Section Two</h2>
```
