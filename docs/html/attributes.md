# HTML Attributes

Attributes give extra information about an element. They are always written inside the start tag, as a name and a value.

```html
<a href="https://example.com">Visit Example</a>
```

Here `href` is the attribute name and the web address is its value.

## Common attributes

| Attribute | Used for |
| --- | --- |
| `href` | The link address of an `a` element. |
| `src` | The file path of an image, video or audio. |
| `alt` | Alternative text for an image. |
| `width`, `height` | Size of an image. |
| `style` | Inline CSS styling. |
| `lang` | Language of the content. |
| `title` | Extra text shown as a tooltip. |

## Rules

- Always put values in quotes, preferably double quotes.
- Use lowercase attribute names.
- Separate multiple attributes with spaces.

```html
<img src="cat.jpg" alt="A sleeping cat" width="300">
```
