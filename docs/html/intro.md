# HTML Introduction

HTML stands for **HyperText Markup Language**. It is the standard language used to create web pages.

## What is HTML used for?

HTML describes the structure of a web page. It uses elements, written as tags, to tell the browser what each part of the page is, such as a heading, a paragraph, an image or a link.

## Your first HTML example

```html
<!DOCTYPE html>
<html>
  <head>
    <title>My First Page</title>
  </head>
  <body>
    <h1>Hello, World!</h1>
    <p>This is my first paragraph.</p>
  </body>
</html>
```

## How it works

- `<!DOCTYPE html>` tells the browser this is an HTML5 document.
- `<html>` is the root element of the page.
- `<head>` contains information about the page, such as its title.
- `<body>` contains everything visible on the page.
- `<h1>` is a main heading and `<p>` is a paragraph.
