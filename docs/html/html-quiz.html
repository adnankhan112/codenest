HTML Quiz

Theory​

A quiz shows you what you really know and what you still need to review. Answer each question on your own first. Write your answers on paper, for example 1-A, 2-C, and so on. Then check the answer key at the bottom of the page.

How to read your score:

  • 22 to 25 correct: Excellent. You are ready for the project.
  • 16 to 21 correct: Good. Review the topics of the questions you missed.
  • 15 or fewer: Read the chapters again and repeat the exercises. This is normal. Practice makes it easier.

Practical​

Questions​

1. What does HTML stand for?

  • A. HyperText Markup Language
  • B. High Tech Modern Language
  • C. HyperTool Making Language
  • D. Home Text Markup Level

2. Which line should be the very first line of a modern HTML page?

  • A. <html lang="en">
  • B. <!DOCTYPE html>
  • C. <head>
  • D. <title>

3. Which element makes the largest heading?

  • A. h6
  • B. head
  • C. h1
  • D. header

4. Which code makes a correct link?

  • A. <a>https://example.com</a>
  • B. <link href="https://example.com">Visit</link>
  • C. <a url="https://example.com">Visit</a>
  • D. <a href="https://example.com">Visit</a>

5. Which attribute gives an image a text description?

  • A. title
  • B. alt
  • C. name
  • D. text

6. Which element is meant for the main navigation links?

  • A. nav
  • B. menu
  • C. links
  • D. navigate

7. Which element creates a bullet list?

  • A. ol
  • B. li
  • C. ul
  • D. list

8. Which element makes a table row?

  • A. td
  • B. tr
  • C. th
  • D. row

9. Which of these is a block element by default?

  • A. span
  • B. a
  • C. strong
  • D. div

10. Which attribute must be unique on a page?

  • A. class
  • B. id
  • C. alt
  • D. href

11. Which element shows that a word is important?

  • A. strong
  • B. small
  • C. mark
  • D. sub

12. Where does the visible content of a page go?

  • A. Inside head
  • B. Inside title
  • C. Inside meta
  • D. Inside body

13. Which tag helps a page fit properly on a phone screen?

  • A. <meta charset="UTF-8">
  • B. <meta name="viewport" content="width=device-width, initial-scale=1.0">
  • C. <meta name="phone" content="yes">
  • D. <link rel="mobile">

14. Which element is obsolete and should not be used?

  • A. main
  • B. strong
  • C. font
  • D. section

15. How do you connect a label to an input?

  • A. The label for value matches the input id
  • B. The label name matches the input class
  • C. The label is placed inside head
  • D. They connect automatically

16. Which is the best link text?

  • A. Click here
  • B. Read our beginner HTML guide
  • C. Here
  • D. More

17. How many h1 headings does a page usually need?

  • A. None
  • B. One for every paragraph
  • C. One main h1
  • D. Exactly six

18. Which attribute makes an image load only when it is near the screen?

  • A. loading="lazy"
  • B. speed="slow"
  • C. load="later"
  • D. defer="image"

19. Where do you place the title element?

  • A. Inside body
  • B. Inside head
  • C. Inside footer
  • D. After html

20. What is the minimum color contrast ratio for normal text under WCAG level AA?

  • A. 1.5 to 1
  • B. 2 to 1
  • C. 3 to 1
  • D. 4.5 to 1

21. What must the home page file of a GitHub Pages site be called?

  • A. home.html
  • B. main.html
  • C. index.html
  • D. start.html

22. Which element creates a pop-up dialog window?

  • A. popup
  • B. dialog
  • C. modal
  • D. window

23. Which is the correct way to write an HTML comment?

  • A. // comment
  • B. /* comment */
  • C. # comment
  • D. <!-- comment -->

24. Which of these elements has no closing tag?

  • A. p
  • B. div
  • C. img
  • D. h1

25. Which input type is made for email addresses?

  • A. type="mail"
  • B. type="email"
  • C. type="text-email"
  • D. type="address"

Answer key​

QuestionAnswerWhy
1AHTML means HyperText Markup Language.
2BThe doctype comes first and puts the browser in standards mode.
3Ch1 is the largest and most important heading.
4DA link uses a with an href attribute.
5BThe alt attribute describes the image for people who cannot see it.
6Anav is for groups of main navigation links.
7Cul is an unordered (bullet) list. ol is numbered.
8Btr means table row.
9Ddiv is a block element. The others are inline.
10BAn id must be unique. A class can repeat.
11Astrong marks important text.
12DThe visible content goes inside body.
13BThe viewport meta tag makes the page fit phone screens.
14Cfont is obsolete. Use CSS instead.
15AThe for value of the label must match the id of the input.
16BGood link text describes where the link goes.
17CA page usually has one main h1 that describes the page.
18Aloading="lazy" delays loading until the image is near the screen.
19BThe title element belongs in head.
20DWCAG AA asks for at least 4.5 to 1 for normal text.
21CThe server looks for index.html first.
22BThe dialog element creates a dialog window.
23DHTML comments start with <!-- and end with -->.
24Cimg is a void element and has no closing tag.
25Btype="email" checks the format and shows a helpful keyboard on phones.
