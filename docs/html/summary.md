# HTML Summary and Practice

You have learned the essentials of HTML.

## What you learned

- The structure of an HTML page
- Elements, attributes, headings and paragraphs
- Text formatting, links, images and lists
- Tables, forms and input types
- Semantic elements, the head section and entities
- Audio, video and responsive design

## Practice project

Create a personal page named `index.html` that has:

1. A `header` with your name and a `nav` with three links.
2. A `main` section with an `h2`, a paragraph and an image.
3. A list of your hobbies.
4. A table with your weekly study schedule.
5. A contact form with name, email and message fields.
6. A `footer` with a copyright line.

Continue with the CSS tutorial to learn how to style your pages.
