# HTML Styles

The `style` attribute adds CSS directly to an element.

```html
<p style="color: blue;">This text is blue.</p>
```

## Common style properties

```html
<h1 style="color: white; background-color: darkblue;">Styled heading</h1>
<p style="font-size: 20px;">Larger text.</p>
<p style="font-family: Arial;">Arial font.</p>
<p style="text-align: center;">Centered text.</p>
```

## Note

Inline styles are good for quick tests. For real websites, put CSS in a separate stylesheet. You will learn this in the CSS tutorial.
