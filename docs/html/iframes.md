# HTML Iframes

An `iframe` displays another web page inside your page.

```html
<iframe src="https://www.example.com" width="600" height="400" title="Example page"></iframe>
```

## Notes

- Always add a `title` attribute for accessibility.
- Some websites do not allow themselves to be shown in an iframe.
- Only embed content from sources you trust.

## Embedding a video or map

Services such as video sites and map providers give you an iframe code that you can paste into your page.
