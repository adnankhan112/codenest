# HTML Editors

You do not need special software to write HTML. A plain text editor and a web browser are enough.

## Recommended editors

- **Visual Studio Code**: free, popular and beginner friendly.
- **Notepad** (Windows) or **TextEdit** (Mac, in plain text mode): fine for a first try.

## Steps to create your first page

1. Open your editor and type the code below.
2. Save the file with the name `index.html`.
3. Double-click the file. It opens in your browser.

```html
<!DOCTYPE html>
<html>
  <body>
    <h1>My First Heading</h1>
    <p>My first paragraph.</p>
  </body>
</html>
```

## Tip

Always save HTML files with the `.html` extension, otherwise the browser will not display them as web pages.
