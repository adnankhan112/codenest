# HTML Head and Meta Tags

The `head` element contains information about the page. It is not shown on the page itself.

```html
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <meta name="description" content="Learn HTML step by step.">
  <meta name="author" content="Your Name">
  <title>Learn HTML</title>
  <link rel="stylesheet" href="style.css">
  <script src="script.js" defer></script>
</head>
```

## Common elements in the head

| Element | Purpose |
| --- | --- |
| `title` | The tab title. It is important for SEO. |
| `meta charset` | The character encoding. |
| `meta viewport` | Makes the page work well on phones. |
| `meta description` | A summary shown by search engines. |
| `link` | Connects an external file, such as CSS. |
| `style` | Holds internal CSS. |
| `script` | Adds JavaScript. |
