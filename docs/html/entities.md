# HTML Entities

Some characters have special meaning in HTML, such as the less-than sign. To show them as text, use entities.

| Character | Entity | Description |
| --- | --- | --- |
| less-than | `&lt;` | Shows the less-than sign. |
| greater-than | `&gt;` | Shows the greater-than sign. |
| ampersand | `&amp;` | Shows the ampersand. |
| quote | `&quot;` | Shows a double quote. |
| space | `&nbsp;` | A space that does not break. |
| copyright | `&copy;` | Shows the copyright sign. |

```html
<p>To write a paragraph, use &lt;p&gt; and &lt;/p&gt;.</p>
<p>&copy; 2026 My Website</p>
```

Entities start with an ampersand and end with a semicolon.
