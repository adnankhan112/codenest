# HTML Block and Inline Elements

## Block elements

A block element always starts on a new line and takes the full available width. Examples: `div`, `p`, `h1` to `h6`, `ul`, `ol`, `table`, `form`.

## Inline elements

An inline element does not start on a new line and only takes the width it needs. Examples: `span`, `a`, `img`, `b`, `strong`, `em`.

## The div element

`div` is a generic block container. It is mostly used to group elements for styling.

```html
<div style="background-color: lightgray; padding: 10px;">
  <h2>A box</h2>
  <p>Content inside the box.</p>
</div>
```

## The span element

`span` is a generic inline container, used to style part of a text.

```html
<p>My mother has <span style="color: blue;">blue</span> eyes.</p>
```
