# Bootstrap Sizing, Borders and Shadows

## Theory

Utility classes also control **width and height**, **borders**, **rounded corners** and **shadows**. These small classes save you from writing CSS.

## Practical

```html
<div class="w-50 bg-light p-2">Half the width</div>
<div class="w-100 bg-light p-2">Full width</div>
<div class="h-25 bg-light" style="height: 200px;">A quarter of the parent</div>
<div class="mw-100">Maximum width 100 percent</div>

<div class="border p-3">Border</div>
<div class="border-top p-3">Border only on top</div>
<div class="rounded p-3 border">Rounded corners</div>
<img src="photo.jpg" class="rounded-circle" width="100" alt="Round photo">

<div class="shadow-sm p-3">Small shadow</div>
<div class="shadow p-3">Normal shadow</div>
<div class="shadow-lg p-3">Large shadow</div>
```
