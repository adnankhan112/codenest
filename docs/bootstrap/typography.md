# Bootstrap Typography

## Theory

**Typography** means how text looks. Bootstrap sets good default fonts and sizes, and gives you classes for headings, text size, weight, alignment and more.

## Practical

```html
<h1>Heading 1</h1>
<h2 class="display-4">Big display heading</h2>
<p class="lead">A larger, important paragraph.</p>

<p class="fw-bold">Bold</p>
<p class="fst-italic">Italic</p>
<p class="fs-1">Large text (fs-1 to fs-6)</p>
<p class="text-center">Centered</p>
<p class="text-end">Aligned right</p>
<p class="text-uppercase">uppercase</p>
<p class="text-decoration-underline">Underlined</p>
<p class="text-truncate" style="max-width: 150px;">A very long text that gets cut</p>

<blockquote class="blockquote">
  <p>A quote text.</p>
</blockquote>
<small class="text-muted">Small gray text</small>
```
