# Bootstrap Buttons

## Theory

A **button** lets the user take an action. Bootstrap styles buttons with the `.btn` class, plus a color class such as `.btn-primary`.

## Practical

```html
<button class="btn btn-primary">Primary</button>
<button class="btn btn-secondary">Secondary</button>
<button class="btn btn-success">Success</button>
<button class="btn btn-danger">Danger</button>
<button class="btn btn-warning">Warning</button>
<button class="btn btn-outline-primary">Outline</button>
<a href="#" class="btn btn-link">Link style</a>

<!-- Sizes -->
<button class="btn btn-primary btn-lg">Large</button>
<button class="btn btn-primary btn-sm">Small</button>

<!-- Full width -->
<div class="d-grid">
  <button class="btn btn-success">Full width button</button>
</div>

<!-- Disabled -->
<button class="btn btn-primary" disabled>Disabled</button>

<!-- Button group -->
<div class="btn-group">
  <button class="btn btn-outline-dark">Left</button>
  <button class="btn btn-outline-dark">Middle</button>
  <button class="btn btn-outline-dark">Right</button>
</div>
```
