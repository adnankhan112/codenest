# Bootstrap Introduction

## Theory

**Bootstrap** is a free **CSS framework** for building good looking, **responsive** websites quickly. A framework is a ready-made set of rules and parts that you reuse.

Responsive means the page looks right on every screen: phone, tablet and computer.

Bootstrap gives you:

- A **grid system** to arrange content in rows and columns.
- Ready **components**: buttons, navbars, cards, forms, modals and more.
- Many **utility classes** for spacing, colors and text.
- Some JavaScript for interactive parts (menus, popups and sliders).

It was first made by Twitter. Today it is one of the most used frontend tools in the world.

## Practical

Compare plain HTML with Bootstrap:

```html
<!-- Plain HTML: looks very basic -->
<button>Click me</button>

<!-- With Bootstrap classes: a nice blue button -->
<button class="btn btn-primary">Click me</button>
```

You do not write the CSS. You only add **class names** to your HTML.
