# Bootstrap Summary

## Theory

Bootstrap is a quick way to build responsive websites. With its grid, components and utility classes, you can make a good looking page by adding only class names.

## Practical

## What you learned

Containers, the grid and breakpoints, typography, colors, spacing, sizing, flexbox utilities, buttons, images and tables, forms and validation, navbar, cards, alerts, list groups, modals, dropdowns, accordion, tabs and carousel, offcanvas and toasts, icons, customization with dark mode, and a full landing page project.

## Next steps

1. Build the practice projects.
2. Learn **JavaScript** well to make your pages interactive.
3. Try other tools such as **Tailwind CSS** and a framework such as **React**.
