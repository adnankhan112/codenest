# JavaScript Summary and Practice

## What you learned

Variables, data types, operators, strings, arrays, objects, conditions, loops, functions, events, the DOM, forms, JSON, dates, classes, async code and error handling.

## Practice projects

1. A to-do list: add and remove items using the DOM.
2. A counter with plus, minus and reset buttons.
3. A form with validation for name and email.
4. A simple calculator for two numbers.
5. A page that loads users from an API and shows them in a list.
