# JavaScript Syntax

```javascript
let x = 5;
let y = 6;
let z = x + y;
console.log(z); // 11
```

## Rules

- Statements are separated by semicolons.
- JavaScript is case sensitive: `myVar` and `myvar` are different.
- Names can contain letters, digits, `_` and `$`, but cannot start with a digit.
- Use camelCase for names, such as `firstName`.

## Comments

```javascript
// single line comment

/* multi
   line comment */
```
