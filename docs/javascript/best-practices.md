# JavaScript Best Practices

- Use `const` and `let`, avoid `var`.
- Use `===` instead of `==`.
- Give variables and functions clear names in camelCase.
- Keep functions short and focused on one job.
- Handle errors with try and catch.
- Avoid global variables.
- Add comments only where the code is not obvious.
- Load scripts with `defer`.
- Validate user input.
