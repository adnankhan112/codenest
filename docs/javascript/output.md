# JavaScript Output

JavaScript can show output in several ways.

```javascript
console.log("Shown in the browser console");
alert("Shown in a popup");
document.getElementById("demo").innerHTML = "Written into the page";
document.write("Written directly (not recommended)");
```

Open the console in your browser by pressing **F12** and choosing the Console tab. It is the best place to test code.
