# TypeScript Summary

## Theory

TypeScript adds a type system to JavaScript. It finds mistakes early, helps your editor give better suggestions, and makes big projects easier to maintain.

## Practical

## What you learned

Types, arrays, tuples, enums, unions, intersections, functions, objects, interfaces, classes, inheritance, abstract classes, generics, utility types, type guards, modules, async code, error handling, the DOM, Node.js, advanced types and a full project.

## Next steps

1. Build the practice projects.
2. Learn a framework that uses TypeScript: **Angular**, **NestJS** or **React with TypeScript**.
3. Read the official handbook at typescriptlang.org.
