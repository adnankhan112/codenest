# Node.js Summary

## What you learned

Node.js basics, modules and npm, the file system, events, HTTP servers, streams and buffers, callbacks, promises and async/await, the event loop, Express (routing, middleware, templates, REST APIs), databases (MySQL and MongoDB), authentication with bcrypt and JWT, sessions, file uploads, validation, security, WebSockets, worker threads, testing, debugging and deployment.

## Next steps

1. Build the practice projects.
2. Learn **TypeScript** to write safer Node.js code.
3. Learn a frontend framework such as React and connect it to your Node.js API.
