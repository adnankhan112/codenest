# Node.js Introduction

Node.js lets you run **JavaScript outside the browser**, on your computer or on a server.

## Why Node.js?

- You use one language (JavaScript) for the frontend and the backend.
- It is fast and good at handling many users at the same time.
- It has a huge library collection called **npm**.
- It is used by Netflix, PayPal, LinkedIn and many others.

## What can you build?

- Websites and APIs
- Chat apps and real time apps
- Command line tools
- Server side programs and automation scripts

## First program

Create `hello.js`:

```javascript
console.log("Hello from Node.js!");
```

Run it:

```
node hello.js
```
