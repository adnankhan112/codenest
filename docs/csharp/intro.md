# C# Introduction

C# (say "C sharp") is a modern programming language created by Microsoft. It is simple, powerful and runs on the .NET platform.

## What is C# used for?

- Windows and desktop apps
- Web applications and APIs (ASP.NET)
- Games (the Unity game engine)
- Mobile apps (.NET MAUI)
- Cloud services

## First program

```csharp
using System;

class Program
{
    static void Main()
    {
        Console.WriteLine("Hello, World!");
    }
}
```

In newer versions you can also write only:

```csharp
Console.WriteLine("Hello, World!");
```
