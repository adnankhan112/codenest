# C# Math

```csharp
Console.WriteLine(Math.Max(4, 9));      // 9
Console.WriteLine(Math.Min(4, 9));      // 4
Console.WriteLine(Math.Sqrt(64));       // 8
Console.WriteLine(Math.Pow(2, 5));      // 32
Console.WriteLine(Math.Abs(-7));        // 7
Console.WriteLine(Math.Round(4.6));     // 5
Console.WriteLine(Math.Ceiling(4.1));   // 5
Console.WriteLine(Math.Floor(4.9));     // 4
Console.WriteLine(Math.PI);

var rnd = new Random();
Console.WriteLine(rnd.Next(1, 7));      // 1 to 6
```
