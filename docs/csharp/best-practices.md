# C# Best Practices

- Use PascalCase for classes and methods, and camelCase for variables.
- Keep methods short and focused.
- Use properties instead of public fields.
- Use `string interpolation` (`$"..."`) instead of joining text with `+`.
- Use `TryParse` for user input.
- Use `using` for files and database connections.
- Use `async` and `await` for slow operations.
- Use `List<T>` and `Dictionary<K, V>`, not old collections.
- Never ignore exceptions.
- Write clear names and comments for hard parts.
- Test your code with xUnit or NUnit.
