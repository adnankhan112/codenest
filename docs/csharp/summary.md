# C# Summary and Practice

## What you learned

Syntax, variables, operators, strings, conditions, loops, arrays, methods, classes, inheritance, polymorphism, interfaces, collections, exceptions, files, lambda, LINQ, generics and async code.

## Practice projects

1. A console calculator.
2. A student record system using `List` and classes.
3. A bank account program with properties and exceptions.
4. A to-do list saved in a file.
5. A word counter using `Dictionary`.

## Next steps

Learn **ASP.NET Core** to build websites and APIs, or **Unity** to make games with C#.
