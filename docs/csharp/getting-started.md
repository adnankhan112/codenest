# C# Getting Started

## What you need

1. The **.NET SDK**. Download it from dotnet.microsoft.com.
2. An editor such as **Visual Studio** or **VS Code**.

## Check the installation

```
dotnet --version
```

## Create and run a project

```
dotnet new console -o HelloApp
cd HelloApp
dotnet run
```

The file `Program.cs` holds your code. `dotnet run` builds and runs the program.
