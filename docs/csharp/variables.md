# C# Variables

```csharp
int age = 20;
double price = 9.99;
char grade = 'A';
bool passed = true;
string name = "Ali";

var city = "Lahore";        // the compiler finds the type
age = 21;
const double PI = 3.14;     // cannot change
```

## Naming rules

- Use letters, digits and underscores.
- Do not start with a digit.
- Use camelCase, such as `firstName`.
