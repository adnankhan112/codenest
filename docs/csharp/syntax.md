# C# Syntax

```csharp
using System;

namespace MyApp
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Hello");
        }
    }
}
```

- `using System;` brings in common tools such as `Console`.
- A `namespace` groups classes.
- `Main` is where the program starts.
- Every statement ends with a semicolon.
- C# is **case sensitive**.
- Class and method names use PascalCase (`MyMethod`). Variables use camelCase (`myValue`).
