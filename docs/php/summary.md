# PHP Summary

## What you learned

PHP basics, strings, arrays, functions, forms and validation, cookies and sessions, files and uploads, dates, regex, JSON, exceptions, object oriented programming (classes, inheritance, abstract classes, interfaces, traits, magic methods, namespaces), PHP 8 features, MySQL with PDO, CRUD, security, Composer, REST APIs and a login system.

## Next steps

1. Build the practice projects.
2. Learn a framework such as **Laravel**.
3. Learn **Node.js** or **Python** to see how other server languages work.
