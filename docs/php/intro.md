# PHP Introduction

PHP stands for **PHP: Hypertext Preprocessor**. It is a popular language that runs on a **web server** and makes websites dynamic.

## What can PHP do?

- Create pages that change for each user
- Read data from forms
- Work with databases such as MySQL
- Handle logins, shopping carts and payments
- Build APIs for mobile apps

## Who uses PHP?

WordPress, Facebook (in the past) and Wikipedia use PHP. About three out of four websites with a known server language use PHP.

## First program

```php
<?php
echo "Hello, World!";
?>
```

PHP code runs on the server. The visitor only sees the result (HTML), never the PHP code.
