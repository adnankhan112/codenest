# Go Summary

## Theory

Go is a simple, fast and practical language, with built-in tools for concurrency. It is a great choice for servers, cloud software and command line programs.

## Practical

## What you learned

Variables and types, control flow, arrays, slices and maps, functions and closures, pointers, structs and methods, interfaces, composition, errors, packages, generics, goroutines, channels, select and mutexes, context, files, JSON, HTTP servers and clients, testing and a REST API project.

## Next steps

1. Build the practice projects.
2. Learn a web framework such as **Gin** or **Echo**, and a database library.
3. Read the official tour at **go.dev/tour**.
