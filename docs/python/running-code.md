# Running Python Code

There are three common ways to run Python code.

## 1. The interactive shell

Type `python` in a terminal and press Enter. You can type one line at a time and see the result at once.

```
>>> 2 + 3
5
>>> print("Hi")
Hi
```

Type `exit()` to leave.

## 2. A script file

Save your code in a file such as `app.py` and run it:

```
python app.py
```

## 3. An editor such as VS Code

1. Install the **Python** extension in VS Code.
2. Open your `.py` file.
3. Click the **Run** button at the top right.

## Tip

Use the shell for quick tests and script files for real programs.
