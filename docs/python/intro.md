# Python Introduction

Python is a programming language. A programming language is a way to give instructions to a computer. Python is famous for being easy to read and easy to learn, because its code looks close to normal English.

Python was created by Guido van Rossum and was first released in 1991. Today it is one of the most popular programming languages in the world.

## What is Python used for?

| Area | Example |
| --- | --- |
| Websites | Building the server side of a website |
| Data and AI | Working with data, charts, and machine learning |
| Automation | Renaming files, sending emails, and doing boring tasks automatically |
| Games and tools | Small games, command-line tools, and helpers |
| Learning | Many schools and universities teach Python first |

## Why learn Python first?

- The code is short and clear.
- You can write a useful program in a few lines.
- It has a very large community, so help is easy to find.
- The skills you learn help you with other languages later.

## Install Python

1. Go to [python.org/downloads](https://www.python.org/downloads/) and download the newest version for your computer.
2. Run the installer. On the first screen, tick **Add Python to PATH**, then click **Install Now**.
3. Close and reopen your terminal, then check the installation:

```text
python --version
```

If you see a version number that starts with 3, Python is ready.

## Your first program

Create a file named `hello.py` and write this line:

```python
print("Hello, CodeNest!")
```

Run it in the terminal:

```text
python hello.py
```

The screen shows:

```text
Hello, CodeNest!
```

`print()` is a function that shows text on the screen. The text inside the quotes is called a string.

## Comments

A line that starts with `#` is a comment. Python ignores it. Use comments to explain your code.

```python
# This line is a comment
print("Python ignores the comment above")
```

## Try it yourself

1. Install Python and check it with `python --version`.
2. Create `hello.py` and make it print your own name.
3. Add a comment above the `print` line that explains what it does.
4. Add a second `print` line that shows your city, then run the file again.

## Quick summary

- Python is an easy and popular programming language.
- It is used for websites, data, automation, games, and learning.
- `print()` shows text, and a line that starts with `#` is a comment.
